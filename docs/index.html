Completely Air-Gapped

CloudManager runs entirely inside your terminal environment. It operates locally with no external telemetry, SaaS platforms, or third-party web configurations—your credentials never leave your machine.

Local Fuzzy Search Index

Querying public cloud APIs directly on every keystroke causes latency and rate limits. CloudManager loads resource configurations into local memory, facilitating instant, high-speed matching.

Multi-Cloud Aggregator

Instantly query AWS, GCP, Azure, and Kubernetes resources within a single tabbed viewport layout. There's no need to switch browser tabs, log in, or deal with MFA fatigue across various cloud console pages.

Download & Install

Build the Go executable binary on your system with a single installation command.

# Build and install production binaries
$ go install github.com/vyoogam/cloudmanager@latest
